WHY · 解决什么问题

折腾 DSH 的那些坑，
一个个填掉。

a manager for the whole ecosystem

01
装了个插件，DSH 就起不来了？
图形化关停、降级问题插件，让 DSH 正常启动——不用翻配置文件。
02
升级 DSH，所有插件全失效？
多个 DSH 版本共存互不影响，复制已有 Profile 从容适配新版。
03
不想一个一个装插件试？
内置整合包市场，像装 Minecraft 整合包一样，一键导入整套配置。
04
不想开命令行，还想多开几个？
任意「版本 × Profile」多实例并行，端口自动分配，图形化启停重启。
05
网络不好，下载总失败？
镜像轮询 + 便携运行时，不依赖你系统的 Node / Git，大陆无 VPN 开箱即用。
CAPABILITIES · 核心能力

一个界面，管住整个 DSH。

从本体版本到插件开关，从 Profile 到整合包分享，全部图形化完成。

i

多版本环境

下载 / 扫描多个 DSH 本体，新旧版本共存。任意「环境 × Profile」自由组合，切换版本不丢插件。

ii

插件管理

内置市场 + NPM / GitHub / 本地安装，拉杆启停、一键更新、版本豁免、依赖修复，装坏可回退。

iii

Profile 管理

新建 / 删除 / 重命名 / 导入导出，右键备注与适配版本，拖拽排序，同名多来源精确区分。

iv

整合包 .dspack

遵循 DSH-PackForge 开放规范，导出 / 导入 / 在线市场，SHA-256 校验，自动重建依赖。

v

多实例并行

独立进程、端口从 3080 自动分配，互不冲突。「打开界面」直达带 token 的 Web UI。

vi

开箱即用

便携 Node / pnpm / Git 自动就绪，全程无黑框、不改系统 PATH，镜像轮询应对弱网环境。

MODPACK · 整合包生态

像分发 Minecraft 整合包一样，分发你的 AI 工作流。

一个 .dspack 就是一套完整的配置快照：插件组合、依赖、补丁、适配版本。 不含 node_modules 与凭据，体积小、可安全分享，导入即用。

QUICK START · 四步跑起来

从下载到 Web 界面，
比装个播放器还快。

STEP 01

下载安装

便携单文件解压即用，或用安装包装好。运行环境会自动准备。

STEP 02

获取 DSH 环境

一键下载官方多版本，或扫描电脑上已装的 DSH 本体。

STEP 03

初始化 Profile

一键初始化开箱即用，也可导入整合包 / 新建空白配置。

STEP 04

选组合，启动

任选「环境 × Profile」启动，点「打开界面」直达 DSH Web UI。
