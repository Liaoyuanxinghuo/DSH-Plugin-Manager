📦 整合包（Modpack）.dspack v3manifest v5
像 Minecraft 整合包一样，一键导出、分享、安装 DSH AI 智能体配置包 —— 遵循 DSH-PackForge 开放规范

📤 导出（Pack）

  • 点击 Profile 行的「⬆ 导出」→ 切换为「整合包（.dspack）」
  • 自动生成 manifest v5：bundles / dependencies / patch / dshVersion
  • 自动排除 node_modules · 运行数据 · 凭据 · 压缩包
  • 返回 SHA-256 校验值，可安全分享给任何人

📥 导入（Install）

  • 「⬇ 导入」→ 选「整合包」→ 在线市场或本地文件
  • 校验容器与 SHA-256 → 落盘 overrides/ 与 home/
  • 自动重建依赖（pnpm install 流式日志）
  • 重名自动改名；全局文件覆盖前自动备份可回滚

🌐 市场（Market）

  • 内置 dsh-pack-market 索引浏览
  • 展示名 / 描述 / 作者 / bundle 数 / 所需 DSH 版本
  • 下载后校验 size + SHA-256，防篡改
  • 导入即用，无需手工配置

🔄 完整流程

第一步
选择导出类型
完整 zip（含数据）或整合包（仅配置 + 插件）
→
第二步
填写包名 / 版本

→
第三步

pnpm install 逐 profile 重建，日志实时可见

🗂 包结构（profile 形态）

my-pack-1.0.0.dspack（标准 ZIP） ├── dspack.json ← 容器标记 { "format": "dspack", "version": 3 } ├── manifest.json ← manifest v5：bundles / dependencies / patch / dshVersion ├── package.json ← 机器文件快照（导入时由 manifest 权威重建） ├── pnpm-lock.yaml ← 依赖锁定（可选） └── overrides/ ← 用户文件 → $DSH_HOME/profiles/<name>/ ├── cordis.patch.yml ← 补丁层 └── … ← 其余用户文件 （可选 home/ → $DSH_HOME 全局 skill / preset / AGENTS.md）

  • 适配版本下拉直接选择左栏 DSH 版本 —— 仅作提示，无任何约束
